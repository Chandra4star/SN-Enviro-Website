## 🏢 About The Company

Founded in **January 2017** by a team of seasoned technocrats with over **100+ years of combined experience**, **SN Enviro Solutions Pvt. Ltd.** has established itself as a leading system integrator, manufacturer, and supplier in the environmental sector. 

Our core mission is to enable industries, smart cities, and governments across the globe to achieve strict environmental compliance through highly precise, cutting-edge monitoring technologies. We specialize in:
- **CAAQMS** (Continuous Ambient Air Quality Monitoring Stations)
- **CEMS** (Continuous Emission Monitoring Systems)
- **EQMS** (Effluent Quality Monitoring Systems)
- **WMS** (Weather Monitoring Systems)
- **IIoT Data Loggers** & Remote Calibration Units

## 📖 About The Project

This repository houses the digital front-end architecture for SN Enviro. It is a premium, high-performance web application designed to reflect the technological superiority of our environmental solutions. 

Built from the ground up for speed and aesthetics, the website operates as both a stunning digital brochure for prospective clients and a secure gateway for administrative control. It features a modern glassmorphism design language, highly fluid physics-based animations, and a flawlessly responsive layout that adapts to any device.

---

## ✨ Key Features

- 🌓 **Dynamic Theming:** Seamless Light and Dark mode toggles with highly tailored Tailwind color palettes ensuring perfect contrast.
- 📱 **Flawlessly Responsive:** Pixel-perfect optimization across all devices (Mobile, Tablet, Desktop) with global overflow protection.
- 🎬 **Cinematic Animations:** Powered by Framer Motion, featuring tumbling/rolling typography, staggered fade-ins, and physics-based interactions.
- 🖼️ **3D Gallery Stack:** An interactive, physics-driven photo stack component that allows users to endlessly cycle through our environmental project showcases.
- 🤝 **Infinite Client Slider:** A smooth, auto-scrolling marquee proudly displaying our corporate partners and clients.
- 🗺️ **Premium Assets:** Integration of high-resolution photography, custom SVG wireframe mapping, and polished icon sets via Lucide React.

---

## 💻 Tech Stack & Architecture

### Frontend Layer
* **React 18**: Component-based UI architecture.
* **Vite**: Next-generation frontend tooling for instant server starts and lightning-fast HMR.
* **Tailwind CSS v4**: Utility-first CSS framework for rapid, responsive UI development.
* **Framer Motion**: Production-ready animation library for React used for complex physics-based micro-interactions.
* **React Router DOM**: Client-side routing for seamless page transitions.
* **Lucide React**: Beautiful, consistent iconography.

## 🖱️ How to Use the Website

The website is designed for intuitive exploration:

1. **Navigation:** Use the sticky, frosted-glass Header to jump between sections (Home, About Us, Services, Products, Clients, Contact).
2. **Theme Switching:** Click the Sun/Moon icon in the navigation bar (or mobile menu) to switch between Light and Dark mode. All UI elements, shadows, and backgrounds will dynamically adjust.
3. **Interactive 3D Gallery:** Scroll down to the "Our Work" section and simply **click or tap** the image stack. The top image will fluidly slide out and rotate to the back of the pile, allowing you to cycle through our installations infinitely.
4. **Product Routing:** Clicking on specific solutions in the dropdown menu or the footer will auto-scroll you precisely to the relevant technology section on the page.

## 🔐 Admin Portal (Partner Portal)

The application includes a secure, integrated **Admin Portal** designed for internal staff and authorized partners.

* **Access:** Accessible via the `/admin` route or by clicking "Admin Portal" in the navigation menu.
* **Capabilities:** 
  * Authenticate securely into the backend system.
  * Manage dynamic website content (updating Hero text, About Us information, Contact Details).
  * Upload and manage new project images for the 3D Gallery.
  * Monitor active client inquiries submitted via the Contact form.
