## 📖 About The Project

**SN Enviro Solutions** is a state-of-the-art web application built for a leading environmental system integrator. Since 2017, SN Enviro has been delivering cutting-edge online monitoring systems for air, water, and emissions. 

This platform serves as the digital front door for the company, featuring a highly premium, modern, and interactive user interface designed to showcase complex environmental technology (like CAAQMS, CEMS, and EQMS) with striking clarity.

---

## ✨ Features

- 🌓 **Dynamic Theming:** Seamless Light and Dark mode toggles with highly tailored Tailwind color palettes and glassmorphism UI elements.
- 📱 **Flawlessly Responsive:** Pixel-perfect optimization across all devices (Mobile, Tablet, Desktop) with global overflow protection.
- 🎬 **Cinematic Animations:** Powered by Framer Motion, featuring tumbling/rolling typography, staggered fade-ins, and physics-based interactions.
- 🖼️ **3D Gallery Stack:** An interactive, physics-driven photo stack component that allows users to endlessly cycle through project showcases.
- 🤝 **Infinite Client Slider:** A smooth, auto-scrolling marquee to proudly display partners and clients.
- 🗺️ **Premium Assets:** High-resolution photography integrations, custom SVG mapping, and polished icon sets via Lucide React.
- ⚡ **Lightning Fast:** Built on Vite for instant server starts and lightning-fast Hot Module Replacement (HMR).

---

## 💻 Tech Stack

### Frontend
- **Framework:** [React 18](https://reactjs.org/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Routing:** [React Router DOM](https://reactrouter.com/)
